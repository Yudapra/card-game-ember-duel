Ember Duel: an original turn-based card duel. You are the last ember-mage of the Ashen Court, and three rivals hold the road to the Ember Throne. Outdraw them, outplay them, and take back the fire.

40 spells across 4 suits (Flame hits hard, Frost shields and heals, Gale draws and energises, Thorn burns), 3 rivals with their own decks and personalities (Pip the aggro Spark Thief, Mara the healing Tidecaller, Gorrum the grinding Stone Warden), a draft after every rival falls, Ember Chain combos, burn and shield statuses, synthesized WebAudio sounds, and full keyboard + mouse play. Everything runs offline from static files — no network request, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and press Play. (Or serve `game/` with any static HTTP server and open `game/index.html`.)

Play: click a card (or press 1–7) to play it, Space or End turn to pass, R to restart, M to mute, H for the rules.
